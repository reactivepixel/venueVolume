## Records in `tour.json`

19 model records total: 13 grounded in available exact-model manufacturer pages/specification content, and 6 additional current Martin MAC discoveries. Several have null dimensions and acquisition errors because the reviewed pages do not provide a resolved dimensional drawing, image URL, or complete exact-model specifications. Those nulls are deliberate; no physical dimensions, DMX modes, or protocols were inferred. Volero Twins and B-Eye 7 have nonstandard continuous pan/tilt limitations called out in modeling notes.

Every record uses official manufacturer URLs. Direct official image URLs are present only where actual page markup exposed them in this pass (Rivale Profile, MAC One Beam, Volero Cube). Empty image arrays and `acquisition_errors` are an explicit hold on model acquisition, not a buildable image package. A later acquisition pass should prioritize exact-model imagery and dimensional drawings before generating geometry. This batch does not yet satisfy the requested full six-brand model inventory: Ayrton's additional official index discoveries, ROBE's dynamic exact-item index, and uncovered GLP / Vari-Lite / Claypaky variants remain discovery-to-record work, not just image follow-up.

## Evidence and caveats

- Martin's MAC family page provided exact current model links and its moving-head overview names significant legacy models.
- Claypaky's official product index provided exact new product names and model codes; product pages were opened for the cited Volero Cube, Volero Twins, B-Eye 7 and Arolla Aqua records.
- Ayrton's official index is a discovery list; this pass opened Rivale Profile and its official specification sheet. Other Ayrton index items have not yet been promoted into JSON records.
- GLP and Vari-Lite indexes establish product-family coverage but the current catalog already contains many top touring models. Do not import existing IDs a second time.
- ROBE's products page is a dynamic application. Plain HTML reveals series and the product collection is rendered from embedded data; the full item-by-item inventory was not conclusively extracted here.
- The existing `research/fixtures/expansion/tour.json` contains prior batch records. Those entries are not copied into this batch; matching IDs in `assets/fixtures/catalog.json` remain excluded.
