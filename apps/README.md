# Applications

- [design-studio](design-studio/README.md): browser workspace for venues, fixture inventory, Load Outs, Tours, palettes, phasers, numbered cues and simulated rehearsal.
- [marketing](marketing/README.md): Astro private-alpha landing page.
- [visionos](visionos/README.md): native spatial fixture placement, selection Toolbox, palette/phaser programmer, cue playback and room navigation.
- [roomScan](roomScan/README.md): movie references → reviewed geometry → Blender → USDZ and environment manifest → Xcode import.

The venue intake service queues roomScan extraction and model builds. Gaussian splat generation and the separate visionOS, Unity and Unreal splat viewers have been retired.
