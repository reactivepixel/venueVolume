# UX audit fixes — 2026-10-03

Release: v0.2.4, from local dev v0.2.3 (e28596d). Work was split between the adaptive preset editor, portable-save worker, and integration/wrist UI, each in an owned branch/worktree. This addresses the implementation findings in [the preceding audit](2026-10-03-ux.md). Physical acceptance remains separate.

## Changes and review

- Resizable windows replace fixed content sizing. The editor uses a compact preset picker at narrow widths or accessibility text sizes, stacks actions and switches channels to one column. Sliders expose channel names and current values. The entire editor, including footer/errors, scrolls.
- The wrist library has distinct Fixtures and Presets tabs. The library and inspector stack at large accessibility sizes. Scene information, room settings and setup actions scroll/wrap rather than relying on the former 410-point region. Launch and New venue have scrollable outer content and a bounded, scalable inner venue list.
- Targeting/manual controls now use a normal, movable Venue controls window for everyone. There are no interactive children on the head anchor. Targeting/transform opens it; the Toolbox menu can reopen it. Closing cancels pending targeting and ends transform mode. System default placement replaces a low utility-panel placement observed during capture.
- Fixture labels show names until selected; selected labels expose Info/Delete and a consolidated actions menu. Labels maintain a minimum angular size through distance scaling. At most six nearby, non-overlapping labels appear, with the selected fixture prioritized. Hidden labels do not hide fixtures; the wrist scene list remains available. Large-text selected labels stack their action buttons. Reduce Motion is respected for selection transitions.
- Portable-save read/decode/hash, scan validation, native-asset staging/validation and export encoding run away from the main actor. Import has an available Cancel checking button. A request checks cancellation and navigation intent again before publishing staged files. Existing immutable room files are fingerprinted to reject changes during preparation. Final metadata checks and atomic moves are still synchronous; Foundation decode itself is not interruptible mid-call.
- Independent review caught an unbounded preset-window minimum size, an inspector whose header could consume the scroll area, label position jumps from inconsistent scaling, and offscreen labels consuming the visible-label budget. These were corrected before integration.

This uses the Apple spatial-layout/accessibility/buttons guidance linked in the preceding audit; it is not a claim of complete HIG compliance.
