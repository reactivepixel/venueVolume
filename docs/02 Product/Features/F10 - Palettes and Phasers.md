# Palettes and phasers

Venue Volume uses **palettes** for reusable static attribute values and **phasers** for cyclic multistep effects. Existing `preset`, `presetID`, drag tokens, window IDs and portable-save JSON keys remain compatible; the name changes in the UI do not invalidate saved shows. The former F10 document remains as a compatibility entry point.

Start with an intensity, color, position or beam palette. Select the channels that it owns: applying a color palette leaves dimmer, aim and unrelated controls intact. Duplicate a baseline entry to customize it without modifying its original assignments. Saving updates all fixtures assigned to that palette, including members of a selected group. Physical fixture profiles still determine actual channel meaning; the sample room uses the synthetic VV Preview 16 profile and does not output manufacturer DMX.

The baseline native library includes Full, Half, Blackout, White, Warm, Red, Blue, Center, Narrow and Wash palettes, plus Dimmer chase, Dimmer breathe, Red / blue, Pan sweep and Circle phasers. The SaaS library supplies corresponding semantic intensity/color/position examples. A phaser consists of 2–32 steps with independent channel values and positive widths. Speed is BPM, measure is beats per complete cycle, phase shifts the cycle and phase spread distributes offsets across selected fixtures at `index × spread / count`; a 360° spread places two fixtures at 0° and 180°, without a duplicated endpoint. Transition 0 holds each step then snaps; transition 1 linearly interpolates across its whole width. Intermediate transition values hold then interpolate. Width changes the fraction of the cycle occupied by a step. Duplicate and customize step values, widths, speed, measure, phase and transition.

The native editor pins an independent white sample room with floor and wall grid lines above the scrolling controls. Its cube starts 1 m above the floor. Select the cube to expose X/Y/Z handles and drag one axis at a time. Lighting samples the current draft continuously even with no venue fixture selected. Assigned fixture preview and SaaS live playback sample phasers on their render clocks; manual programmer values take precedence in the SaaS console.

This is a focused console-inspired implementation, not a grandMA3 show-file importer or full console engine. It does not yet implement relative/additive layers, easing acceleration/deceleration, recipes, MAtricks, speed masters, selective/global/universal fixture resolution, embedded palette references or network DMX playback. Position effects use the current fixture's channel personality; sample beam output is intentionally synthetic.

MA Lighting calls its static reusable values presets and its effects engine phasers. Venue Volume uses the broader palette name to distinguish static attribute libraries from dynamic effects. Sources: [grandMA3 presets](https://help.malighting.com/grandMA3/2.4/HTML/presets.html), [grandMA3 phasers](https://help.malighting.com/grandMA3/2.4/HTML/phaser.html), [Phaser Editor](https://help2.malighting.com/grandMA3/2.3/HTML/phaser_editor.html). Those references inform the workflow; Venue Volume's measure and transition definitions above are the implemented contract.
