## Current focus

1. Identify the first user and the lighting workflow worth improving.
2. Prove deterministic output timing on representative hardware.
3. Establish a fixture model that supports real-world devices without excessive setup.
4. Test an interaction model that remains safe and fast during live operation.

## Documentation rules

- Prefer one durable concept per note and link related notes with `[[wikilinks]]`.
- Use ISO dates (`YYYY-MM-DD`) and put the date in experiment, meeting, and decision records.
- Separate observed evidence from interpretation.
- Mark unknowns clearly; do not silently turn assumptions into requirements.
- Update an existing canonical note instead of creating a second source of truth.
